# Local Prompt Studio v3.1.1 — Руководство пользователя

[README](../../README.md) | [English](en-US.md) | [日本語](ja-JP.md) | [简体中文](zh-CN.md) | **Русский** | [한국어](ko-KR.md)

## 1. Обзор

Local Prompt Studio — настольное приложение Windows, которое с помощью локальной языковой модели GGUF подготавливает промпты для моделей изображений и видео. Доступны три основных режима: **Prompt Generation**, **AI Chat** и **Библиотека промптов**.

Поддерживаются профили MiniMax H3, Wan 2.2, LTX-2.3, Krea 2 и Anima; каждый профиль выбирает собственный Renderer и формат результата. ComfyUI не требуется, если вы не отправляете готовый промпт в его workflow. Приложение Portable, не требует установщика и хранит постоянные данные в распакованной папке.

## 2. Требования и загрузка

- Windows 10／11 x64.
- Папка, доступная для записи.
- Достаточный объём System RAM для выбранного GGUF и Context Size.
- Для Vulkan — совместимый GPU и рабочий драйвер.
- Python, Git, pip, CUDA, права администратора и ручная настройка PATH не требуются.

Загружайте Windows Portable ZIP только с [официальной страницы GitHub Releases](https://github.com/tarou61300/Local-Prompt-Studio/releases/latest). GGUF и `mmproj` не входят в архив. Не используйте EXE из неофициальных источников.

Сверьте ZIP с `SHA256SUMS.txt` из того же Release:

```powershell
Get-FileHash .\Local-Prompt-Studio-<version>-win-x64-portable.zip -Algorithm SHA256
```

## 3. Первые 10 минут

1. Распакуйте ZIP в новую доступную для записи папку; не запускайте приложение внутри архива.
2. Запустите `LocalPromptStudio.exe`.
3. При начальной настройке выберите существующий GGUF.
4. Сначала выберите **CPU** либо устройство **Vulkan GPU**, обнаруженное llama.cpp.
5. Выберите **Категория**, **Модель**, **Вариант** и **Задача**.
6. Введите описание в **Запрос (язык определяется автоматически)**.
7. Нажмите **Создать промпт**.
8. Проверьте редактируемый результат, затем используйте **Копировать**, **Сохранить как TXT** или сохраните его через **Библиотека промптов → Новый промпт**.

## 4. Начальная настройка

Кнопка выбора GGUF указывает на существующий `.gguf` на ПК. Приложение не копирует и не загружает модель автоматически. После перемещения или удаления файла выберите его снова.

Текущая рекомендация: Qwen3-8B Q4_K_M для более высокого качества и Qwen3-4B Q4_K_M для ПК с меньшим объёмом памяти. Это ориентир, а не гарантия совместимости любого GGUF или квантования.

Только MiniMax H3 требует официальный H3 Prompt Skill. При явном запросе загрузки он сохраняется в `data/skills` Portable-папки. Wan 2.2, LTX-2.3, Krea 2 и Anima этот Skill не используют.

Если сомневаетесь, начните с CPU. Если Vulkan-версия llama.cpp обнаружила устройство, можно выбрать Vulkan и нужный device. Проверьте итоговые параметры и завершите настройку.

## 5. Backend, Context и память

- **CPU** — стандартный и резервный вариант; **Потоки CPU** задают число потоков.
- **Vulkan GPU** позволяет выбирать только **Устройство Vulkan**, указанное `llama-server --list-devices`.
- **GPU Offload** по умолчанию Auto; опытный пользователь может задать число layers.
- Доступны Context 4096, **8192 — Recommended**, 16384 и 32768. В 4096 могут не поместиться полный H3 Skill, ввод и вывод; большие значения требуют больше памяти.
- Интерфейс показывает Available RAM／Total RAM. Память GPU при unified memory не прибавляется к System RAM повторно.
- При предупреждении закройте другие приложения, уменьшите Context Size или выберите меньший GGUF.
- Максимальное ожидание генерации Prompt или Chat — 300 секунд.

Приложение управляет одним внешним процессом llama-server. Он переиспользуется при одинаковых model, backend, device, Context и thread и перезапускается только при необходимости. **Выгрузить модель** завершает принадлежащий приложению server и освобождает память; следующая генерация загрузит модель снова. Cancel, timeout и закрытие приложения также останавливают только его собственный server.

## 6. Prompt Generation

Выберите **Категория**, **Модель**, **Вариант**, **Задача** и **Стиль преобразования промпта**. Основное описание вводится в **Запрос**; при наличии у Задачи используйте общие дополнения и дополнения начального／конечного изображения. **Автоматически добавлять теги качества** управляет только терминами качества Renderer; введённые пользователем термины сохраняются.

Используйте **Создать промпт**, **Отмена** и **Создать заново**. Результат можно редактировать, копировать, сохранить как TXT, открыть через **Перевести и редактировать** или **Отправить в ComfyUI**. Anima показывает Positive и Negative отдельно. Текущий Bridge отправляет только Positive; Negative копируется отдельно.

Единственный источник выбора Task — поле Задача в UI. Текст Запроса Task не меняет. Для I2VA／Ref2VA действует Task Schema Lock: schema другой Task отклоняется без автоматического исправления, retry или смены Task. Сообщение показывает выбранную Task и, если возможно, несовпадающие top-level fields. Формат задают Profile и Renderer. Названия Model, Task token вроде `I2VA` и schema field не переводятся.

## 7. Подсказки по вводу, Literal Content и Protected Terms

**Подсказки по вводу** добавляют в Запрос примеры timing, фиксированной camera, cut, speech и visible text. Они не анализируют медиафайлы. Явно указывайте временные интервалы, намерение camera／cut, реплики и видимый текст.

Для точного совпадения используйте парные Literal-маркеры:

```text
[speech:ja]おかえりなさい。[/speech]
[text:en]OPEN[/text]
[speech:zh]你好[/speech]
[speech:ru]Привет[/speech]
[speech:ko]안녕하세요[/speech]
```

Парные блоки могут быть многострочными. Старый однострочный вид, например `[speech:ru] Привет`, поддерживается до конца строки; парные markers имеют приоритет. Текст сохраняется в Prompt точно, а marker удаляется. Protected Terms также сохраняются. При ошибке validation результат не принимается. Диагностика указывает исходное поле, способ обнаружения, число символов и короткий идентификатор без показа самого текста. Проверьте Запрос и свёрнутые дополнения.

## 8. Редактор перевода промпта

Язык вывода Profile является исходным, а выбранный **Язык интерфейса** — целевым. Текущие Builtin Profile выводят английский Prompt:

- 日本語 UI: English ↔ Japanese.
- 简体中文 UI: English ↔ Simplified Chinese.
- Русский UI: English ↔ Russian.
- 한국어 UI: English ↔ Korean.
- При английском UI и английском Profile кнопка **Перевести и редактировать** скрыта.

**Защищать структуру** отделяет структуру Skill, Protected Terms и Literal Content от перевода. При открытии выполняется только первый перевод Original→язык UI, а **Автоперевод** остаётся выключенным. Если включить его, синхронизация происходит через одну секунду после остановки ввода; при выключенном режиме используйте **Обновить перевод**. Проверка revision отбрасывает устаревшие ответы. **Применить** возвращает в Prompt сторону Original на языке вывода Profile — для текущих Builtin это английский. После смены языка UI перезапустите приложение.

## 9. AI Chat и Vision

AI Chat использует общий с Prompt Generation GGUF или отдельный Chat GGUF. Одновременно в памяти находится одна model; при переключении текущий принадлежащий приложению server безопасно завершается. Контекст хранится в текущей chat session.

Для изображений назначьте подходящий `mmproj` эффективной Chat model. Через **+ Изображение** или Drag & Drop принимаются PNG, JPG／JPEG и статический WebP. Animated WebP не поддерживается. Статический WebP нормализуется в PNG в memory и отправляется localhost llama-server.

Через **+ Текстовый файл** или Drag & Drop можно прикрепить один поддерживаемый текстовый документ или файл исходного кода. Поддерживаются UTF-8, UTF-16 с BOM и японская кодировка Windows CP932; лимит — 512 КиБ. Двоичные, пустые и неподдерживаемые файлы отклоняются. PDF, документы Office, аудио и видео не поддерживаются. Текст хранится в memory и обрабатывается только локальным llama-server приложения; для текстового вложения `mmproj` не требуется.

**Анализировать** создаёт обычный ответ Chat. **Анализ референса промпта** формирует model-independent данные для Prompt Generation. Проверьте transfer preview и через **Отправить в дополнение промпта** добавьте данные в Запрос, общее дополнение либо дополнение начального／конечного изображения.

Изображения, Chat и Prompt не отправляются во внешний cloud и обрабатываются только локальным llama-server приложения.

## 10. Библиотека промптов

Библиотека промптов независима от Истории. Запись содержит Title, Model, Task, Tags и точный текст Prompt. Избранное и подсказки существующих Tag помогают повторно использовать Tags. Поиск использует Model, Task, Title и Tags; несколько Tags объединяются условием AND. Выбор Tag запускает поиск автоматически. После удаления последнего Tag все записи автоматически не показываются — при необходимости нажмите **Поиск**.

Выбор строки показывает детали Prompt. Редактирование metadata меняет Title／Tags, но не Prompt, Model, Task или идентификатор. Можно копировать одну или несколько отмеченных записей; удаление требует подтверждения. В **Настройки** задаётся число строк Tags, результатов и минимальных строк деталей Prompt.

## 11. Наборы данных Prompt Library

Старый `data/prompt_library.sqlite3` остаётся **Default Dataset** и автоматически не перемещается. **Новый набор данных** создаёт независимую Library; selector переключает их; **Загрузить набор данных** импортирует допустимую SQLite Library как управляемую копию; **Экспортировать набор данных** создаёт переносимую копию database. Активный Dataset запоминается.

Prompts, Tags и состояние избранных Tags разделены между Datasets. Dataset merge не реализован.

Для переноса из v3.0.0 закройте обе версии и выберите старый `data/prompt_library.sqlite3` через **Библиотека промптов → Загрузить набор данных** в новой версии. Source DB проверяется и не перемещается. Не распаковывайте новую версию поверх старой; сохраните старую папку как backup. Для Library используйте export／load. Общей автоматической миграции или merge для Settings, History и дополнительных Datasets нет, поэтому не предполагайте поддержку копирования отдельных внутренних файлов.

## 12. Интеграция с ComfyUI

Интеграция необязательна.

1. Закройте ComfyUI и скопируйте `ComfyUI-Bridge/MMH3PromptBridge` в `ComfyUI/custom_nodes/MMH3PromptBridge`.
2. Перезапустите ComfyUI и откройте или обновите browser.
3. Откройте **Настройки → Интеграция с ComfyUI**.
4. Для локального сервера оставьте `http://127.0.0.1:8188` и нажмите **Проверить подключение**.
5. Нажмите **Сопрячь с ComfyUI**, сравните шестизначный code и только при совпадении нажмите **Allow** в ComfyUI.
6. Щёлкните правой кнопкой целевой text／Prompt node и выберите **MMH3 Prompt Bridge → Set as MMH3 Target**, затем STRING／multiline STRING widget.
7. Создайте или отредактируйте Prompt и нажмите **Отправить в ComfyUI**.

Отправка только заменяет текст выбранного widget в текущем browser workflow. Она не ставит workflow в queue, не запускает генерацию, не делает broadcast и не использует `/prompt` API. После browser reload или смены workflow／tab может понадобиться повторный выбор target. Для удалённого ComfyUI обязателен HTTPS; не публикуйте ComfyUI без аутентификации в internet. Credential защищён Windows DPAPI CurrentUser; ручного token workflow нет. Browser JavaScript UI расширения остаётся английским.

## 13. Справочник настроек

- **Путь к LLM-модели**: GGUF Prompt Generation.
- **Backend вывода**, **Устройство Vulkan**, **Потоки CPU**, **GPU Offload**, **Размер контекста**: выполнение llama.cpp и память.
- **Расположение Skill**: MiniMax H3 Skill и обновления.
- **История**: необязательная локальная история, по умолчанию выключена.
- **Тема**, **Язык интерфейса**: внешний вид и locale; новый язык применяется после перезапуска.
- **Модель AI Chat**, `mmproj`: общая или отдельная Chat model и projection-файл для каждой model.
- **Библиотека промптов**: строки Tags／результатов и минимум строк деталей.
- **Интеграция с ComfyUI**: URL, проверка соединения и pairing.

Настройки Portable не изменяют файлы GGUF.

## 14. Portable-данные, конфиденциальность и offline

Постоянные данные находятся в `data` рядом с приложением:

- `data/config.json`
- `data/local-prompt-studio.log`
- `data/llama-server/`
- `data/history.sqlite3`
- `data/prompt_library.sqlite3`
- `data/prompt_library_datasets.json`
- `data/prompt_library_datasets/<dataset-id>/prompt_library.sqlite3`
- `data/skills/h3-prompt-writing/`
- `data/comfyui_credentials.dat`

Приложение не хранит настройки в Registry, не устанавливает Windows service и не создаёт Start Menu shortcuts. Для удаления закройте приложение и удалите распакованную папку. Нет telemetry, рекламы и analytics. Обычная генерация использует выбранный GGUF и `127.0.0.1`. Network нужен только для явно выбранных действий: получение／проверка H3 Skill, открытие официальной страницы model, ComfyUI Test Connection／Pair／Send. Запросы и созданные Prompts обычно не пишутся в log. Credential ComfyUI защищён DPAPI CurrentUser, не передавайте его другим. После подготовки данных обычная генерация работает offline.

## 15. Обновление и резервное копирование

1. Закройте приложение и дождитесь завершения llama-server.
2. Оставьте старую release-папку как backup; не распаковывайте новый ZIP поверх неё.
3. Распакуйте новую версию в отдельную доступную для записи папку.
4. Пользовательские данные находятся в старой папке `data`; копируйте backup только при закрытом приложении.
5. Prompt Library переносите через **Экспортировать набор данных** в старой версии и **Загрузить набор данных** в новой. `data/prompt_library.sqlite3` из v3.0.0 загружается напрямую.
6. Удаляйте старую папку только после проверки новой. Можно сохранить Release ZIP, `SHA256SUMS.txt` и backup.

Cloud synchronization, автоматического Dataset merge и общей автоматической миграции всех Portable-данных нет.

## 16. Устранение неполадок

- **Нельзя записать настройки**: распакуйте в папку, доступную вашей учётной записи; не запускайте из ZIP.
- **Модель не задана**: выберите существующий GGUF в Настройки; он не копируется.
- **Нет H3 Skill**: только для MiniMax H3 получите официальный Skill при наличии internet.
- **Vulkan Device не найден**: проверьте драйвер или выберите CPU; обнаружение выполняет llama.cpp.
- **Мало Context**: используйте 8192 либо 16384 при достаточной памяти и сократите ввод.
- **Мало RAM**: закройте программы, снизьте Context или выберите меньший GGUF.
- **Медленная генерация**: CPU может работать несколько минут; максимум ожидания 300 секунд.
- **После Cancel ещё идёт завершение**: подождите несколько секунд. При закрытии приложение остановит только собственный server.
- **Нет связи с ComfyUI**: проверьте запуск ComfyUI, Bridge, browser reload и URL.

При обращении в [GitHub Issues](https://github.com/tarou61300/Local-Prompt-Studio/issues) укажите версию Windows, CPU／GPU, имя GGUF, backend, Context Size, точный error и соответствующие logs из `data/llama-server/`. Не публикуйте приватные Запросы, Prompts, credentials или персональные данные.
